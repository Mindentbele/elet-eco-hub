Több, mint kosár — landing page
================================

Ez egy önálló statikus oldal (egy HTML fájl + .htaccess).
Nincs build, nincs npm — csak töltsd fel a tartalmat a tobbmintkosar.hu cPanel public_html mappájába.

Tartalom:
- index.html      — a teljes landing oldal
- .htaccess       — caching, biztonság, HTTPS
- robots.txt      — keresőknek

Telepítés cPanelen:
1) Lépj be a cPanelbe → File Manager → public_html
2) Töröld a régi tartalmat (vagy mentsd el)
3) Tölsd fel a tobbmintkosar-landing.zip tartalmát ide
4) Ellenőrizd: nyisd meg a https://tobbmintkosar.hu címet

Szerkesztés:
